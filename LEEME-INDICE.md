# Índice del Administrador Móvil
Una línea por documento: la pregunta que contesta (su «Cuándo leerlo»). Se actualiza en el mismo commit que el documento.

| Documento | Cuándo leerlo |
|---|---|
| `AGENTS.md` | Siempre que se trabaje en publicar o administrar una app móvil. |
| `docs/protocolo-apps.md` | Al abrir la conversación de una app nueva, antes de pedir una publicación y al revisar una solicitud. |
| `docs/requisitos-play.md` | Antes de decidir si una versión puede subirse, al planificar una app nueva o si Play Console rechaza algo. |
| `docs/publicar-en-play.md` | Al llevar una app por primera vez a Play, o para saber en qué paso está. |
| `docs/firma-y-claves.md` | Al crear la clave de una app, al firmar, al dar un APK a un amigo o si se pierde o filtra una clave. |
| `docs/api-play.md` | La primera vez (Steven tiene que crear la cuenta de servicio) o si una orden `play` falla. |
| `docs/tecnologia-e-ios.md` | Al empezar una app nueva, al migrar una vieja o cuando Steven quiera iOS. |
| `docs/investigacion-20261020.md` | Para ver la fuente o el matiz de un dato de requisitos-play.md (HISTÓRICO). |
| `apps/registro.json` | Qué apps hay, su paquete, su carpeta y su instancia del laboratorio (lo leen las herramientas). |
| `apps/<app>.md` | Antes de hablar con la conversación de una app o de revisar una solicitud suya. |
| `apps/<app>-encargo.md` | Al lanzar la conversación de una app o para saber qué se le pidió. |
| `plantillas/SOLICITUD.md`, `RESPUESTA.md`, `AGENTS-app.md` | Al pedir o contestar una publicación, o al preparar el `AGENTS.md` de una app. |
| `plantillas/politica-privacidad.md` | Al preparar la ficha de una app (paso 5 de `docs/publicar-en-play.md`). |
| `PENDIENTES.md` | Al empezar una sesión: qué falta y quién lo tiene que hacer. |
| `CAMBIOS.md` | Para saber por qué algo es como es (bitácora numerada con su commit). |
| `..\Android Laboratorio\AGENTS.md` | Para manejar el emulador real: arrancar, tocar, ver, guiones y evidencias. |
